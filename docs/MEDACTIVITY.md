# MedActivity implementation notes

`med_activity_graph` is a deterministic multichannel image transform inspired
by Medformer's multi-granularity patching and router interaction. It computes
local activity at three temporal patch scales, propagates activity between
correlated channels, exchanges information between scale-level router signals,
and maps fine/medium/coarse activity to the RGB planes. The original
`activity_graph` mode remains unchanged.

#### Visual feature shapes

The visual branch does not expose patch tokens to the feature cache or fusion
head. With the maintained 224x224 CLIP ViT-H/14 setup, the selected transformer
layer temporarily produces `[B,257,1280]` (256 patches plus CLS). `mean`
aggregation removes CLS and averages the patch tokens; `cls_token` selects CLS.
The frozen `ln_post` and 1280-to-1024 projection then produce one `[B,1024]`
vector per rendered image.

- `line_plot` renders each sensor channel independently and concatenates the
  pooled vectors, producing `[B,C*1024]` (`[B,6144]` for six channels).
- `multichannel_line_plot`, `activity_graph`, and fixed
  `med_activity_graph` each render one image per sample and produce
  `[B,1024]`.
- `[B,197,768]` is not retained by this implementation and is not the token
  shape of the maintained ViT-H/14 model.

#### Adaptive temporal granularity

Adaptive selection applies only to `med_activity_graph`. “Granularity” is the
temporal patch length used to aggregate local activity, not a different channel
group, graph-node count, or input-window length. Each regime is still a full
RGB image: its three patch lengths populate the fine/medium/coarse RGB planes.
The default complete regimes are relatively fine `(1,2,4)`, legacy/base
`(2,4,8)`, and relatively coarse `(4,8,16)`.

The same frozen visual encoder maps the bank
`[B,K,3,224,224] -> [B,K,1024]`; features are cached as `[B,K*1024]`, and the
trainable selector reduces them to `[B,1024]` before Mantis fusion. This is not
a GNN, so no separate GNN projection is used. Adaptive runs store checkpoint
and per-sample selector diagnostics under `results/.../atgs/<dataset>/`.
Adaptive feature caching requires resolved local model snapshots so the full
checkpoint contents can be hashed; use a local snapshot or disable
`--feature_cache_dir` for unpinned remote model IDs.

The four maintained multimodal commands preserve the CLIP ViT-H/14 +
Mantis-8M + concat-attention framework and use seed 42:

```bash
DRY_RUN=1 bash scripts/run_med_activity_multimodal.sh shimmer10
DRY_RUN=1 bash scripts/run_med_activity_multimodal.sh pads11
DRY_RUN=1 bash scripts/run_med_activity_multimodal.sh ucihar
DRY_RUN=1 bash scripts/run_med_activity_multimodal.sh falltl
```

UCIHAR uses the official subject-disjoint protocol. FallTL is split by
`(activity_code, trial_no)`, keeping the eight body-part recordings of one
event together, and all sequences are resampled to a common length determined
by `FALLTL_TARGET_LENGTH` (default 2048). Results generated by the former
file-level FallTL split are not comparable with this corrected protocol.

The transform is exposed as `MedActitivy_graph` in
`src/med_activity_graph.py`; `MedActivityGraph` is provided as a conventional
spelling alias. This preprocessing module borrows Medformer principles but is
not the learned Medformer classifier.
